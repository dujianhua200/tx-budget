## 提取口径与注意事项

1. **本参考文件是一份结算书**：各表标题含“结算”字样
   （如“建设项目总结算表”）。v2 输出的是**预算书**，标题须按“预算”口径命名，
   不得直接照抄参考文件中的“结算”字样；预算书各表标题的具体字样待与 451 号文
   编制规程对照确认。
2. **字体以转换后文件实测为准**：标题 18pt 加粗、信息行 9pt、表尾 10pt、
   正文中文 10pt、数值用宋体 10pt。转换后文件中部分中文单元格字体显示为
   `Noto Sans CJK SC`，可能是 LibreOffice 对原字体的替换；v2 实现时若需与原文件
   逐字一致，应在 WPS/Excel 中打开原 `.xls` 再核对一次字体。
3. **转换后文件中的数值是文本型字符串**（`numFmt=@`，`data_type=s`），不是公式。
   v2 不得照抄这一点：v2 由计算引擎算出数值后写入，数值单元格应为数值型。
4. **页边距为转换后实测值**（英寸，括号内为换算成厘米的近似值），原文件可能以厘米为单位，
   转换存在舍入；v2 实现时以英寸值或厘米近似值任选其一，保持各表相对关系即可。
5. **表尾的编制人、编制日期是数据字段**，不是固定文本；v2 按工程信息填充。
6. **表格编号**形如 `-总`、`-1`、`-2`、`-3甲`、`-3乙`、`-3丙`、`-4甲A`、`-5甲`，
   即 `-` 前缀 + 表后缀；v2 按表生成。

## 全局版式规则（全部 11 张表共用）

- 纸张：A4（`paperSize=9`），横向（`landscape`），缩放 100%，`fitToPage` 关闭。
- 无打印区域（`print_area` 为空）、无重复标题行（`print_title_rows` 为空）、
  无 Excel 页眉/页脚对象（`oddHeader`/`oddFooter` 为空）——
  **表头、表尾、页码全部是单元格内文本**，不是 Excel 的页眉页脚功能。
- 标题行：18pt 加粗，居中。封面标题 36pt 加粗，居中。
- 信息行（工程名称/建设单位/表格编号/页码）：9pt；除页码右对齐外其余左对齐。
- 表尾签名行：10pt，左对齐，前导空格用于视觉间距；
  格式为 `施工负责人：` / `审核：` / `编制：<编制人>` / `编制日期：<YYYY年M月D日>`。
- 数据行高：16.55pt 为主；默认行高 15.2pt。
- 边框：表头行上下用 medium 粗线；数据行用 thin 细线；每表最右侧列带右边框。
- 页码：单元格内文字 `第X页 共Y页`（不是 Excel `&P`/`&N` 代码），
  位于信息行最右侧，右对齐；v2 必须按实际分页逐页生成。
- 空白填充行：各表在数据区与表尾之间用空白行把表尾顶到固定行——
  **固定版式，不是流式排版**。表尾行号见各表小节。
- 唯一的手动分页符在表三甲第 29 行之后（第 1 页 = 第 1–29 行，第 2 页 = 第 30–58 行）；
  多页的表三甲在第 2 页重复标题行 + 信息行 + 列头（单元格内重复，非打印标题行）。

**参考文件实测的打折机制（本样本折扣率 37.9%）：**

| 类别 | 机制 | 样本核对（元，误差 < 0.02） |
|---|---|---|
| 打折项 | 折后 = 折前 × 37.9% | 人工费 192918.18→73115.99；技工费 144687.55→54836.58；普工费 48230.63→18279.41；机械 5580.00→2114.82；仪表 15455.26→5857.54；社保 54981.68→20838.06；公积金 8083.27→3063.56；危伤保险 1929.18→731.16；企管 52859.58→20033.78；利润 38583.64→14623.20；生产工具 2893.77→1096.74；点交清理 6366.30→2412.83；车辆 9645.91→3655.80 |
| 不打折项 | 折后表中用 ÷37.9% 冲回，与折前值相等 | 文明施工费：折后 2893.77 = 折后人工费×1.5%÷37.9%（折前 2893.77）；规费：折后 64994.14 = 折后(社保+公积金+危伤)÷37.9%（折前 64994.13，差 0.01 为舍入） |

**证据说明（重要）：** 在本参考文件中，表二两张表**均无“安全生产费”行**；
安全生产费出现在表五甲（见第 10 节）。因此“折后表里安全生产费保持折前值”
在本参考中的落地是：**安全生产费的取费基数用折前建安工程费，不随 37.9% 打折下调**。
实现时若某工程的表二内含安全生产费行，同样适用“不打折、保持折前值”规则——
按“不打折项清单”统一处理，不对安全生产费单独写死逻辑。

**可定制要求（高度定制的一部分）：**

- 折扣率（如本样本的 37.9%）做成可配置项，不写死。
- 不打折费用项清单（如安全生产费、文明施工费、规费等）做成可配置项，不写死；
  默认清单以本参考文件实测的不打折项为准（文明施工费、规费、安全生产费）。
- 打折规则随配置方案一起保存与导出（见配置方案需求）；不同工程 / 不同配置方案
  可使用不同打折规则。
- 打印导出时两张表都要出；折后表的“依据和计算方法”列须体现打折关系，
